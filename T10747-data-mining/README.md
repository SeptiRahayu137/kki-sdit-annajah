# Data Mining
## Proyek: Website & Sistem Informasi SDIT An-Najah Islamic School

## 1. Gambaran Rencana Analisis Data
Folder ini disiapkan untuk menyimpan alur pengolahan data, *Jupyter Notebook* (`.ipynb`), dataset yang digunakan, serta ringkasan *Data Insights* terkait operasional dan data pendukung **SDIT An-Najah Islamic School** dengan pendekatan **CRISP-DM** (pemahaman bisnis, pemahaman data, persiapan data, pemodelan, evaluasi, dan penyajian insight).

## 2. Rencana Artefak & Struktur
- **Notebook Analisis (`.ipynb`)**: Proses eksplorasi data, pembersihan data, pemodelan/analisis pola, dan visualisasi.
- **Dataset**: Menyimpan dataset pendukung yang telah disesuaikan dan aman dari paparan data pribadi sensitif.
- **Data Insights**: Ringkasan temuan utama dan rekomendasi praktis untuk pihak sekolah.
