# Sistem Informasi & Website Sekolah — SDIT An-Najah Islamic School

Repositori utama Kuliah Kerja Industri (KKI) untuk proyek website dan sistem informasi **SDIT An-Najah Islamic School** (Tim 3 Orang: Mhs A, Mhs B, dan Mhs C) yang dipetakan ke 5 mata kuliah[cite: 1, 8, 11]:

- `T10746-framework/` — Pemrograman Berbasis Framework[cite: 2, 8]
- `T10729-ppl/` — Proyek Perangkat Lunak (PPL)[cite: 3, 8]
- `TI0748-sqa/` — Penjaminan Mutu Perangkat Lunak (SQA)[cite: 4, 8]
- `T10747-data-mining/` — Data Mining[cite: 5, 8]
- `TI0745-hukum-ti/` — Hukum dan Kebijakan Teknologi Informasi[cite: 6, 8]
