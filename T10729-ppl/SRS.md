# Software Requirements Specification (SRS)
## Proyek: Website & Sistem Informasi SDIT An-Najah Islamic School

## 1. Gambaran Umum Sistem
Sistem ini merupakan website dan sistem informasi **SDIT An-Najah Islamic School** yang dikembangkan oleh tim beranggotakan 3 orang (**Septi, Zara, dan Hema**) untuk memenuhi konversi 5 mata kuliah KKI:
- **TI0746**: Pemrograman Berbasis Framework
- **T10729**: Proyek Perangkat Lunak (PPL)
- **TI0748**: Penjaminan Mutu Perangkat Lunak (SQA)
- **T10747**: Data Mining
- **TI0745**: Hukum dan Kebijakan Teknologi Informasi

## 2. Kebutuhan Fitur Utama
1. **Beranda & Profil Sekolah**: Menampilkan identitas SDIT An-Najah Islamic School, visi & misi, serta keunggulan sekolah.
2. **Program, Guru/Jurusan & Ekstrakurikuler**: Menampilkan informasi program pendidikan, data guru/jurusan, dan kegiatan ekstrakurikuler.
3. **Berita & Dokumentasi**: Menampilkan berita sekolah dan dokumentasi kegiatan.
4. **Kontak & Formulir PPDB**: Formulir pendaftaran/pertanyaan bagi calon siswa/orang tua yang dilengkapi persetujuan pemrosesan data pribadi (UU PDP) serta informasi lokasi sekolah.
5. **Pengelolaan Data & Autentikasi**: Alur penyimpanan data ke database/API serta akses pengelolaan data sesuai peran.

## 3. Tata Kelola Proyek (PPL)
- **Papan Kanban**: Menggunakan Trello atau GitHub Projects untuk memantau status tugas tim.
- **Strategi Git**: Menggunakan *branch* dan *pull request/code review* pada repositori utama.
- **Peran PPL**:
  - **Septi**: Project Manager
  - **Zara**: System Analyst
  - **Hema**: Technical Lead (Git)
