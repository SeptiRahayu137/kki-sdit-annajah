# Test Plan (SQA)
## Proyek: Website & Sistem Informasi SDIT An-Najah Islamic School

## 1. Tujuan Pengujian
Memastikan kualitas fungsionalitas, tampilan antarmuka (UI), validasi input formulir (termasuk persetujuan data pribadi / UU PDP), serta keandalan API dan alur data pada sistem informasi **SDIT An-Najah Islamic School**.

## 2. Cakupan Pengujian
- **Pengujian Tampilan & Navigasi UI**: Tata letak halaman, keterbacaan teks, responsivitas, dan perpindahan menu/bagian.
- **Pengujian Formulir & Validasi Input**: Formulir PPDB/kontak, validasi kolom wajib, dan persetujuan pemrosesan data pribadi.
- **Pengujian Fungsionalitas & API**: Alur penyimpanan/pengambilan data, autentikasi/hak akses, dan penanganan error.
- **Pelacakan Bug**: Pencatatan temuan *bug*, tingkat keparahan, status perbaikan, dan verifikasi ulang.

## 3. Peran SQA Tim (Septi, Zara, dan Hema)
- **Septi**: QA Lead
- **Zara**: Tester UI dan bug tracking
- **Hema**: Tester API dan validasi
